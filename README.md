# Bloxorz
****
## Descriere

Este o replica dupa jocul de pe Miniclip Bloxorz
realizata in OpenGL, unde se pune accent pe partea grafica,
dar si pe o logica minimala de joc

## Instructiuni de rulare
Va trebui sa cautati si sa descarcati glew, freeglut si glm de pe internet inainte de rula programul.

**Ele sunt excluse de la versionare!**

**Glew,FreeGlut si GLM se adauga relativ la root(adica pe acelasi nivel cu src sau cu CMake-ul)**

**Joc dezvoltat in CLion**
